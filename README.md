## 零基础可以怎么开始

1. 先认一行假名，把平假名和片假名对起来。
2. 每次从下方选 5 个词，先看读音，再遮住读音回忆。
3. 遮住日文，尝试根据中文写出对应的假名。
4. 把单词放回短句里，看看它和助词、动词怎样搭配。
5. 下次先复习没记住的词，再增加新词。

假名表不能替代发音示范。练习听写时，可以让同伴读词，或到在线版听发音后再输入答案；这份 Markdown 本身不播放声音。日语声调和自然语流还需要结合音频学习。

## 从认识汉字到听懂单词

以 `学校` 为例，可以这样检查自己是否真的记住：

- 看见汉字时，能否不看提示读出 `がっこう`。
- 听到读音时，能否写出假名，注意小写的促音 `っ`。
- 放进 `学校に行きます` 后，能否理解整句是“去学校”。

以 `来る` 为例，辞书形读 `くる`，礼貌形式 `来ます` 读 `きます`。不要把所有动词都当成只在原词后面直接加 `ます`，要学习相应的变化。

词表里的 `牛乳` 读 `ぎゅうにゅう`，`今日` 读 `きょう`。拗音中的 `ゅ`、`ょ` 是小写；听写时不要漏掉长音所对应的假名。
